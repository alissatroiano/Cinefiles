## 14-Day Step-by-Step Execution Plan

Designed for **10–12 hours per week** around personal commitments.

### Phase 1: IBM Bob Legal Backend (Days 1–3)
* **Step 1:** Open IBM Bob and prompt it:
  > *"Bob, write a FastAPI Python service that accepts an audio clearance payload (`song_title`, `artist`, `start_time`, `end_time`). Query an external audio API (or mock catalog), calculate estimated Synchronization ($15,000) and Master Use ($15,000) fees, and return a structured JSON response and clearance PDF contract."*
* **Step 2:** Test the generated FastAPI endpoints locally (`/clearance/audio` and `/clearance/approve`).
* **Step 3:** Commit the Python code and `requirements.txt` to `[github.com/alissatroiano/cinefiles](https://github.com/alissatroiano/cinefiles)`[cite: 2].

### Phase 2: Gemini Enterprise Agent Configuration (Days 4–7)
* **Step 4:** Open Google Cloud Console ➔ Agent Builder[cite: 1, 2].
* **Step 5:** Create a Playbook-based Agent and define its core system instruction[cite: 1]:
  > *"You are Cinefiles. Scan uploaded audio timelines for commercial music tracks, ambient radio, or live covers. Extract exact timestamps, song names, and artists. Call `IBM_Bob_Audio_Clearance_Tool` with this metadata."*
* **Step 6:** Register the OpenAPI Webhook tool inside Agent Builder using the schema generated by Bob[cite: 1, 2].

### Phase 3: Runtime SDK Wire-up & Security (Days 8–10)
* **Step 7:** Write a small script using `google-adk` or `google-cloud-aiplatform` to trigger your agent from Python (satisfying the Devpost code inspection rule)[cite: 2].
* **Step 8:** Store API keys (e.g., ACRCloud / AudD credentials) inside **Google Cloud Secret Manager**[cite: 1].
* **Step 9:** Maximize Gemini Safety Settings in Agent Builder to satisfy enterprise guardrail criteria[cite: 1].

### Phase 4: UI, Demo Video & Final Submission (Days 11–14)
* **Step 10:** Embed the built-in Agent Builder Web Chat widget into a simple webpage or host it on Replit[cite: 1, 2].
* **Step 11:** Record a 2.5-minute video demonstrating[cite: 2]:
  1. Uploading a video/audio clip with a background music track.
  2. Gemini identifying the song title and timestamp live.
  3. IBM Bob receiving the webhook and generating the clearance estimate/PDF report.
* **Step 12:** Submit to Devpost before the deadline with your public GitHub URL (`[github.com/alissatroiano/cinefiles](https://github.com/alissatroiano/cinefiles)`), text description, and video link[cite: 2].
